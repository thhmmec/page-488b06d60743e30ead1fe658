品牌简介

节点与线路

实际延迟随运营商与时段变化，建议在客户端内测速后固定常用节点。请勿将账号借出超限设备，以免触发风控。

客户端选择与官网下载指引

兄弟们永远的神不绑定单一 App。请按系统选择主流开源或商店客户端，再导入机场订阅。下列为常用组合，下载请前往各客户端官方渠道，避免来路不明的安装包。

Windows

推荐 Clash Verge 或 v2rayN。复制 Clash / V2Ray 订阅，粘贴到「配置 / 订阅」后更新。系统代理开启后，可按规则分流。

macOS

常用 ClashX.Meta 或 Surge。导入订阅后检查 TUN 或系统代理模式。若需精细分流，可保留国内直连规则。

Android

推荐 Clash Meta for Android。从订阅管理添加链接，允许 VPN 权限。建议关闭电池优化以免后台被杀。

iOS

常用 Shadowrocket、Stash 或 Quantumult X。商店安装后添加订阅 URL，按需开启规则与重写。企业签或不明描述文件请勿使用。

订阅通常同时提供 Clash、Sing-box 与通用链接。一种客户端只需对应格式，重复导入不会增加流量额度。

操作说明

  1. 在官网选择基础版、旗舰版或团队版并完成支付。

日常使用建议

流媒体请选用带解锁标注的节点；游戏优先 IPLC。若某节点突然不可用，先更新订阅再切换。流量将尽时减少大文件下载，或升级套餐。设备超限会表现为新终端无法连上，请在用户中心下线闲置设备。

常见问题

兄弟们永远的神支持哪些客户端下载？

Windows 可用 Clash Verge、v2rayN；macOS 可用 ClashX.Meta、Surge；Android 可用 Clash Meta；iOS 可用 Shadowrocket、Stash、Quantumult X。导入官方订阅即可，无需修改核心协议参数。

机场订阅链接在哪里复制？

登录后在用户中心的订阅栏复制。Clash 链接给 Clash 系客户端，通用或 V2Ray 链接给 v2rayN 等。链接含访问令牌，请勿截图外传。

三个套餐该怎么选？

个人轻度使用选基础版。需要原生流媒体、游戏专线与 5 台设备选旗舰版。多人共用、大流量或要定制路由选团队版。年付比月付少两个月费用。

同时在线设备数超了会怎样？

基础版 3 台、旗舰版 5 台、团队版 20 台。超出后新设备可能无法注册会话，已在线设备不受瞬间掉线影响。在控制台踢出不用的终端即可。

看视频或用 AI 服务失败怎么办？

先确认当前套餐含解锁能力，并切换到标注原生或流媒体的节点。更新客户端规则后重试。若仍失败，提交工单并附节点名与错误时间。

流量用完能否继续加速？

当月额度用尽后新连接会被限制，需等待重置或升级。下载系统更新、云盘同步会快速消耗流量，建议对这些域名直连。
